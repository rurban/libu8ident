# u8ident_c(3) -- C compiler identifier security (TR39 profile)

## SYNOPSIS

`#include <u8ident_c.h>`

`int u8ident_init(enum u8id_profile profile, enum u8id_norm norm, unsigned options);`

`enum u8id_errors u8ident_check(const uint8_t *string, char **outnorm);`

`enum u8id_errors u8ident_check_buf(const char *buf, const int len, char **outnorm);`

`uint32_t u8ident_failed_char(u8id_ctx_t ctx);`

`const char *u8ident_failed_script_name(u8id_ctx_t ctx);`

`const char *u8ident_existing_scripts(u8id_ctx_t ctx);`

`uint8_t u8ident_get_script(uint32_t cp);`

`const char *u8ident_script_name(int scr);`

`void u8ident_free(void);`

## DESCRIPTION

**libu8ident_c** is a stripped-down variant of **libu8ident**(3) for C and
C++ compilers.  It is pre-configured with the **TR39** profile (UTS#39 /
P2528R1), NFC normalization, and always-active Greek-Latin confusable
detection.

It validates UTF-8 identifiers against Unicode security guidelines:

  * XID (Identifier_Status / Identifier_Type) for allowed codepoints.
  * Allowed scripts: Recommended scripts only, 2-script maximum.
  * Mixed-script detection (e.g. Latin + Cyrillic).
  * Confusable detection (Greek-Latin homoglyphs).
  * Combining-mark sequence limits (max 4, NSM prohibitions, duplicate
    combining marks).
  * MEDIAL and bidi control.

The library consists of a single source file and public header.  No
private headers or external dependencies are needed.

## OPTIONS

`u8ident_init()` validates its arguments but ignores them — the profile
and normalization are hardcoded to TR39_4 and NFC.  Pass
`U8ID_PROFILE_TR39_4, U8ID_NFC, 0` for forward compatibility.

## RETURN VALUES

`u8ident_check()` and `u8ident_check_buf()` return:

  * `U8ID_EOK` (0) --
    Valid identifier.
  * `U8ID_ERR_XID` (-1) --
    Not in XID (Identifier_Status / Identifier_Type).
  * `U8ID_ERR_SCRIPT` (-2) --
    Script not allowed (excluded or limited-use).
  * `U8ID_ERR_SCRIPTS` (-3) --
    Mixed-scripts violation.
  * `U8ID_ERR_ENCODING` (-4) --
    Invalid UTF-8 encoding.
  * `U8ID_ERR_COMBINE` (-5) --
    Invalid combining-mark sequence.
  * `U8ID_ERR_CONFUS` (-6) --
    Confusable character (Greek-Latin homoglyph).

## FILES

  * `u8ident-tr39.c` --
    Single-file amalgam source (no preprocessor conditionals).
  * `u8ident_c.h` --
    Public API header.
  * `unitr39.h` --
    Generated TR39 XID lists (self-contained, generated by **mktr39**(1)).

## EXAMPLE

```c
#include <stdio.h>
#include <u8ident_c.h>

int main(void) {
    u8ident_init(U8ID_PROFILE_TR39_4, U8ID_NFC, 0);

    enum u8id_errors r =
        u8ident_check((const uint8_t *)"café", NULL);
    if (r == U8ID_EOK)
        printf("OK\n");
    else {
        u8id_ctx_t ctx = u8ident_new_ctx();
        printf("Error %d at U+%04X (%s)\n",
               r,
               u8ident_failed_char(ctx),
               u8ident_failed_script_name(ctx)
                   ? u8ident_failed_script_name(ctx) : "");
    }

    u8ident_free();
    return 0;
}
```
